# Build guide

Follow the chapters in order. Each one ends with a check so you know it worked before you
move on. Everything up to chapter 6 happens **on the bench with a Raspberry Pi 3** (or 4):
nothing goes into the iPod until the software, click wheel and display all work.

| # | Chapter | You will need |
|---|---|---|
| 1 | [Parts and tools](01-parts.md) | shopping list |
| 2 | [Spotify developer app](02-spotify-app.md) | Spotify Premium, a GitHub account (optional) |
| 3 | [Flash the SD card](03-flash-os.md) | microSD card, Raspberry Pi Imager |
| 4 | [Install the software on the bench Pi](04-install.md) | Pi 3, network |
| 5 | [Click wheel](05-click-wheel.md) | click wheel, FPC breakout, jumper wires |
| 6 | [Display and haptics](06-display-haptics.md) | Adafruit #911, TRRS AV cable (bench), 2N3904, 220 ohm, 1N4148, motor |
| 7 | [Power](07-power.md) | battery, charger, PowerBoost |
| 8 | [Move to the Zero and assemble](08-assembly.md) | Zero 2 W (or Zero W), soldering iron |
| 9 | [Using it](09-using.md) | |
| 10 | [Troubleshooting](10-troubleshooting.md) | |

Wiring diagrams for every step: [../wiring/README.md](../wiring/README.md).

> Safety: lithium cells can catch fire if shorted, punctured or charged wrongly. Work with
> the battery disconnected, insulate every joint, and never charge an unattended build.
